## [v1.0.0] - 2026-11-04

### Added

- Новостная лента: список, просмотр по slug, создание новостей

- Миграция таблицы `news` (quick start через `php spark migrate`)

- Документация: README, CONTRIBUTING, SECURITY, Code of Conduct, формы issues
