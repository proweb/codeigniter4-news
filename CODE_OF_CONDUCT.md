# Code of Conduct

Мы, как участники и мейнтейнеры проекта, обязуемся сделать участие в проекте
комфортным для всех, без харассмента.

- Будьте уважительны и конструктивны.
- Фокусируйтесь на технических достоинствах.
- Исходите из добрых намерений.

Случаи токсичного поведения можно сообщить владельцу репозитория.

*Адаптировано из [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).*
