# Политика безопасности

## Сообщения об уязвимостях

Пожалуйста, **не** открывайте публичный issue для уязвимостей безопасности.

Сообщите приватно:

- Создайте [приватный security advisory](https://github.com/proweb/codeigniter4-news/security/advisories/new), или
- Напишите мейнтейнеру (см. профиль репозитория).

Ответ придёт в течение 7 дней. Пожалуйста, укажите:

- Затронутые версии / коммиты
- Шаги воспроизведения
- Описание последствий

## Поддерживаемые версии

| Версия | Поддержка |
|--------|-----------|
| latest | ✅ |
| старые | ❌ (по возможности) |

## Раскрытие

Благодарим за ответственный disclosure. После выпуска фикса мы упомянем автора отчёта в release notes (если не просят анонимности).
