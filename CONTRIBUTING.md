# Вклад в проект

Спасибо за интерес к проекту! Прочтите этот гайд, чтобы ваш вклад прошёл гладко.

## Начало работы

1. Сделайте форк репозитория.
2. Создайте ветку: `git checkout -b feat/your-feature`.
3. Внесите изменения и сделайте коммит с понятным сообщением.
4. Запушьте ветку и откройте pull request в `main`.

## Чек-лист pull request

- [ ] Описание PR объясняет что и зачем.
- [ ] Тесты проходят локально: `vendor/bin/phpunit`.
- [ ] Новое поведение покрыто тестами.
- [ ] Документация обновлена, если изменилось поведение для пользователя.

## Конвенции для issues

- Используйте формы issues: баг, фича, вопрос.
- Пометьте issue подходящими лейблами: `🐛 bug` / `✨ enhancement` / `🔴 P0`–`🟢 P3`.

## Стиль коммитов

Conventional commits **со scope**: `type(scope): description`

```
feat(news): add slug generation
fix(routes): correct POST detection
```

Типы: `feat` `fix` `docs` `chore` `refactor` `test` `ci` `perf`.
Scope — область изменения (модуль, файл, подсистема).

## Стиль кода

Следуйте существующему стилю проекта.
